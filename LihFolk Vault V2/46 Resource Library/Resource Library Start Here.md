# Resource Library Start Here

A curated link library for Roblox development: official Roblox docs, Luau, Blender docs, the DevForum, well-known GitHub authors and reputable CC0 asset sites. One note per topic, grouped into chapters.

Topic → Subtopic → Sub-subtopic → raw links. Compiled 2026-10-26 from 16 research agents.
Sources are limited to official Roblox (create.roblox.com, about.roblox.com), Luau, Blender docs, the Roblox DevForum, well-known GitHub authors and reputable CC0 asset sites. Exploit, executor, leak, pirated and spam sites were excluded. Links were confirmed through search results, not opened, so a few docs paths may have moved. If one 404s, search its title on create.roblox.com. DevForum threads are community posts, so quality varies.
