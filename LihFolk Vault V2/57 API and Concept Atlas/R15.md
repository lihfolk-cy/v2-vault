## Key facts

- Avoid: No R15 proxy while modelling -> Build the proxy; model on its pivots. ([[Modeling Characters for R15 and Custom Rigs]])
- Route chosen: A (avatar body), B (R15-compatible), or C (custom rig). ([[Modeling Characters for R15 and Custom Rigs]])
- Avoid: Non-R15 StarterCharacter with the default Animate -> Own `Animate` in StarterCharacterScripts. ([[Custom Characters and StarterCharacter]])
- Avoid: Copying real running knee angles onto R15 boxes: the shin enters the pelvis. ([[Locomotion and Melee Reference Numbers]])
- Avoid: Renaming R15 bones. Symptom: the importer does not build a Humanoid, and catalog animations do nothing. ([[Skeleton Library]])
