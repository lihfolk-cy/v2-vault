## In short

Wally is a package manager for Luau with a registry index on GitHub (Wally README). (from [[External Tooling - Rojo Wally Selene StyLua]])

## Key facts

- Tools pinned with Rokit; Wally for packages. ([[Code Pipeline - Rojo Git and CI]])
- Library and version pinned (Wally or packages folder). ([[Declarative UI - React-Lua and Fusion]])
- Commit it for games so everyone gets identical code (the lockfile exists for exactly that, per the Wally README); ignore `Packages/` folders. ([[External Tooling - Rojo Wally Selene StyLua]])
- If your team reviews code in pull requests, shared code belongs in Wally packages or a monorepo, not in Roblox packages. ([[Packages and Asset Reuse]])
