# MemoryStoreService

## In short

`MemoryStoreService` is Roblox's shared, fast, expiring storage: every server of an experience can read and write the same queues, sorted maps and hash maps with low latency, and every item disappears after its time to live (at most 45 days). (from [[MemoryStore Service]])

API snapshot: service, inherits `Instance` (`_tools/roblox_api.json`, docs build of 2026-10-27).
