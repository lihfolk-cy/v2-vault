## In short

FACS: Facial Action Coding System: the standard set of face poses dynamic heads use. (from [[Animation Glossary]])

## Key facts

- Avoid: Same FACS name on two frames -> One frame per pose. ([[Facial Animation and Dynamic Heads]])
- Heads mean FACS. A dynamic head needs face controls and expressions; budget animation time, not just modelling (Facial Animation and Dynamic Heads). ([[Bundles Animation Packs and Emotes for Sale]])
- Facial keys drive the head's FACS controls; see Facial Animation and Dynamic Heads. ([[Animation Capture and Mocap]])
- `FaceControls`: about 50 numeric FACS properties on dynamic heads, animated through FloatCurves or NumberPoses (see Facial Animation and Dynamic Heads). ([[Animation Objects]])
