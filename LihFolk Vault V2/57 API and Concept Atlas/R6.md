## In short

R6 has no elbows, knees, wrists or ankles: one rigid part per limb. (from [[Rigs and Joints]])

## Key facts

- Avoid: Assuming R15 axes on R6 or imported rigs. ([[Motor6D Math and CFrame Composition]])
- Works on an R6/old rig, does nothing on new avatars: code searches for `Motor6D` -> accept `AnimationConstraint` too. ([[Procedural Animation]])
- Imported R6 models sometimes come without some Motor6Ds (missing shoulders). ([[Rigs and Joints]])
- Rigid parts: each box is 100% weighted to one bone, like Roblox's own R6 / R15 bodies. ([[Skeleton Library]])
