# UIDragDetector

## In short

`UIDragDetector` is an instance you parent to a `GuiObject` to make it draggable, with built-in styles (move in a plane, along a line, rotate), bounds, constraint callbacks and events. (from [[Drag-and-Drop Inventories and Sliders with UIDragDetector]])

API snapshot: class, inherits `UIComponent` (`_tools/roblox_api.json`, docs build of 2026-10-27).
