## In short

A reserved server is the standard "holding pen" for the soft-shutdown pattern in Server Lifecycle and Shutdown, a waiting room while a party gathers (Parties and Group Teleports), or a one-player tutorial instance that cannot be griefed. (from [[Reserved and Private Servers in Practice]])

A reserved server is a server of a place that matchmaking never fills; only teleports carrying its access code can enter. (from [[Teleporting and Multi-Place Games]])

## Key facts

- Private server price chosen with "permanent" in mind; free option considered. ([[Reserved and Private Servers in Practice]])
- Private servers have real admin tools. ([[Case Study - Brookhaven RP]])
- Friends kicked from private server: Global idle kick -> Exempt private/reserved servers. ([[AFK Detection Idle Kicks and AFK Reward Rules]])
- Private and reserved servers exempt by default. ([[AFK Detection Idle Kicks and AFK Reward Rules]])
- Server registry with TTL, build version, player counts; private servers excluded. ([[Server Hop Rejoin and Server Lists with Ping]])
