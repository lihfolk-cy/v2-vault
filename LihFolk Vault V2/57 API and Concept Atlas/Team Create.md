## In short

Team Create turns a place into a live shared document: everyone with edit access works in the same data model at the same time, and Studio saves it to the cloud continuously. (from [[Team Create and Collaboration]])

## Key facts

- Age-check compatibility confirmed for every collaborator before they are promised Team Create access. ([[Team Create Permissions and Workflows]])
- Avoid: Reverting while others are editing -> Disable Team Create, then revert. ([[Team Create and Collaboration]])
- Avoid: Restoring during a live Team Create session -> Disable Team Create first. ([[Version History and Backups]])
