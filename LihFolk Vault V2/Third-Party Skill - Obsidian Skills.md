# Third-Party Skill - Obsidian Skills

**Source:** [github.com/kepano/obsidian-skills](https://github.com/kepano/obsidian-skills) by Steph Ango, MIT licence. It is not part of this vault or plugin and nothing from it is included here. Install it from the source and follow its README for the current skill list and install steps. This note is a short original summary written in October 2026.

## What it is

A set of agent skills that teach an AI agent Obsidian's file formats (wikilinks, embeds, callouts, properties, `.base` and `.canvas` files) and related command-line tools, so it can write notes without breaking links or frontmatter.

## Using it with this vault

- **Write in your own folder.** Ask the agent to put new notes in a folder of your own, not in the shipped sections, so a new vault version can be dropped in cleanly. Keep the vault's habits: label sources, no invented numbers, link to existing notes by exact title.
- **Study dashboards and maps.** A Bases view or a canvas over the vault (for example every note tagged `ai-skill`, or a path from [[AI Skills Start Here]] to each skill note) is a quick personal study tracker.
- **Saving research.** If you clip a docs or DevForum page into a note, rewrite it in your own words before sharing; do not paste whole pages into a shared vault.
- **Pair with the research skill.** [[Skill - Roblox Vault Research]] tells an agent how to answer from the vault; Obsidian-format skills tell it how to write vault files correctly.

## Cautions

- Agents can edit or rename many notes at once. Back up or use version control first and review the diff ([[Agent Review Loops and Guardrails in Practice]]).
- Some of its skills call separate command-line tools that must be installed first.
