Steal a Brainrot holds the record for the most concurrent players any single game has ever had. It mixes three familiar ideas: an idle tycoon (things on your base earn money every second), a shop that scrolls past on a conveyor belt, and capture the flag (you can run into another player's base, grab their best unit and carry it home). The theme is "Italian brainrot", a family of absurd AI-generated meme characters that were already viral on TikTok when the game launched.

How to read the labels:
- **Public stats site**: Roblox's public game API, RoMonitor Stats, RoWatcher.
- **Studio statement**: the developers or their company.
- **Press**: news coverage with outlet and date.
- **Observed in the live game (October 2026)**: the public store page, title, icon and thumbnails. Nothing here comes from playing or logging in.

Roblox does not publish CTR, retention or revenue for other people's games. Click-through reasoning below is inference from what is visible.

## 2. Click-through: title, icon and thumbnails

### What is visible today (Observed, October 2026)

- **Title:** `[💀] Steal a Brainrot`. A seasonal emoji in a bracket tag at the front, then a title that is a verb plus the meme noun. No update number.
- **Icon:** a darkened screenshot of the game with a large white hourglass and the words "3 HOURS". This is a countdown icon: the game is telling everyone who sees it that an update or event starts soon.
- **Thumbnails:** 5 images. The first shows a huge white "$997,151,167/s" across the top, a Halloween character named "Spooketti Tualetti" with a rainbow "SECRET" rarity label, standing on a purple conveyor, and a smirking classic avatar to the right. The second uses the same layout with "Skull Lucky Block" and a rainbow "HALLOWEEN" label on an orange conveyor.
- **Description:** five emoji bullet steps ("Buy a Brainrot", "Steal Brainrots from other players", "Generate money", "Rebirth", "Buy slaps and troll gear to troll other players!") and a request to like the game and join the group.

### Why these choices plausibly earn clicks

1. **The verb is the pitch.** "Steal" is a forbidden, exciting verb for a young audience, and it tells you the core interaction before you click. A title that names the action beats a title that names the setting.
2. **Rides an existing meme.** The brainrot characters were already famous on TikTok, so the thumbnail shows faces viewers already recognise. The click is driven by familiarity plus the new twist (you can own them and steal them).
3. **Income per second, not total money.** "$997,151,167/s" is a rate. It promises not a pile of cash but a machine that prints it. That is exactly the idle fantasy.
4. **Rarity label on the unit.** A rainbow "SECRET" tag tells the viewer this is the top of the ladder, which is the thing they want. The same rarity colours appear in game, so the thumbnail is honest about what it is selling.
5. **A smug avatar.** The default-looking avatar with a smirk is the player's stand-in and adds attitude. It is the "I have this and you don't" face.
6. **Countdown icon.** A countdown makes the icon change meaning in a few hours, which gives repeat viewers a reason to look again and a reason to be online when it hits zero. Players learn that the icon is a schedule.

### How it changes per update (Press and public trackers)

The game ships a named update roughly every week (RoWatcher counted Update 44 by early 2026) and the thumbnails always show the newest unit. Event peaks coincide with announced "admin abuse" events, crossovers and concerts, each pre-announced on social media. I could not recover a dated archive of every title variant.

## 3. First five minutes

From the store description and guides (rblxguide.com, updated October 2026; Wikipedia citing PC Gamer and Game Rant):

1. You spawn into a server of up to 8 players and claim a base. Every base sits along a long conveyor that runs through the middle of the map.
2. Characters walk along the conveyor with a price over their head. You start with enough cash to buy a Common one.
3. You buy it, it walks into your base, and your base starts generating money per second immediately. You collect the money from your base.
4. A guide suggests that the first three Commons earn enough to reach the next price tier in about 8 minutes, so the first upgrade decision comes very quickly.
5. Within the first minutes you see other players running into bases, grabbing units and carrying them home, and you learn the lock button on your base: it shields your base for a limited time, after which anyone can steal (guides give 60 seconds base lock time, extended by rebirths; values vary by source and update).

The first five minutes show the entire game: buy, earn, defend, steal. There is no tutorial needed because the conveyor itself teaches the economy (price tags float over every unit) and the other players teach stealing by doing it to you.

See [[First-Time User Experience and Onboarding]] and [[Tycoon Plots and Droppers End to End]].

## 4. Core loop and retention

### The session loop

- **Short loop:** watch the conveyor, buy the best unit you can afford, collect income, lock your base when it expires.
- **Risk loop:** decide whether to leave your base to steal from someone richer. While you are away, your own base is exposed.
- **Long loop:** rebirth. You reset cash and most units in exchange for a permanent income multiplier, more base slots and longer lock time. Guides describe 16 or more rebirth levels with requirements that include specific rare units and very large cash totals (guide sites, 2025 to 2026).

### What makes it sticky

1. **Loss creates attention.** Your best unit can be taken. That makes every session tense and makes players stay to defend. It also created the viral clips of upset children that spread across TikTok and YouTube (Press, Polygon and Game Rant via Wikipedia). Those clips were marketing.
2. **Comeback is always possible.** A player who just lost a unit can go and steal one back. The loss is not permanent unless they give up.
3. **Rare units on a shared conveyor.** Everybody sees the rare unit appear and races for it. The conveyor is a shared lottery visible to the whole server, like Grow a Garden's shared restock but with competition.
4. **Admin abuse events.** The developers join servers and trigger special effects and exclusive units. These are scheduled, announced, and drive the platform's biggest spikes (Press, PC Gamer via Wikipedia; RoWatcher).
5. **Crossovers and concerts.** The admin war with Grow a Garden (August 23, 2025) pushed both games to records; a Bruno Mars concert in January 2026 brought 12.8 million concurrent players and Roblox issued 5.4 million collectibles (Press, GamesIndustry.biz and NME, January 2026).
6. **Countdowns everywhere.** Update countdowns on the icon, in game and on social media make the next spike a date in the calendar.

### The shape of the decline

RoWatcher's early 2026 analysis found each event peak was followed by a steeper drop than the last, settling at around 215,000 concurrent. At 244,383 on October 27, 2026 the game is roughly at that floor (Roblox game API). The audience stays loyal to the brainrot genre more than to any single game: a "Steal An Egg" experience had about 805,000 players at the same moment (Roblox search API, October 27, 2026).

## 5. Monetization

### What the public store page shows (Observed, October 27, 2026)

| Game pass | Price |
|---|---|
| Admin Commands | 7,999 Robux |
| VIP | 375 Robux |
| 2x Money | 299 Robux |

Developer products (lucky blocks, gear, skips) are not listed by Roblox's public API for other games, so the full product list cannot be read from outside. The description openly advertises "slaps and troll gear to troll other players".

### What press reported

- Polygon wrote that "the best items are only available for cash" and noted that server administrator abilities are sold (Press, Polygon, July 25, 2025, via Wikipedia).
- Gear and traps cost in-game money or Robux (Press, Game Rant, July 26, 2025).
- Cheaters used automation scripts for collecting and stealing (Press, Game Rant).

### The shape of the model

A very expensive whale pass (Admin Commands at 7,999 Robux) that lets a player do to a server what the developers do in admin events, a mid-price VIP, a cheap multiplier, plus consumable gear and boxes. Selling power over other players makes money from the competition the game is built on, and it is also the source of almost all the criticism.

## 6. What to copy and what not to copy

### Copy

1. **A shared, visible shop that moves.** A conveyor of priced items that every player can see makes scarcity public and turns shopping into a race. Spawn items on the server from a weighted table; the client only renders. [[RNG Drops and Luck Systems]], [[Drop Tables Rarity and Pity Systems]].
2. **Income per second as the headline number.** Show the rate on the HUD and in thumbnails, not just the total. Rates make growth feel alive. [[HUD Design]].
3. **Risk with a timer.** A base lock with a visible countdown is a simple, readable defence mechanic: everyone understands "you are safe for 60 seconds". It turns attention into a resource. [[Status Effects Buffs and Stacking Rules]] covers timed states.
4. **Rebirth that adds safety, not just multipliers.** Longer lock time and more slots per rebirth reward veterans without making them invincible. [[Rebirth and Prestige System End to End]], [[Pricing Curves and Upgrade Costs]].
5. **Scheduled spectacle.** Countdown icon, announced time, all servers at once. Use [[Cross-Server Messaging]] and plan with [[Event Calendars and Content Planning]].
6. **Crossover with another top game.** The admin war helped both games. Partnerships between non-competing audiences are cheap marketing. [[Short-Form Video Marketing]].
7. **Clear, short store description.** Five emoji bullets that are the whole game. [[Thumbnails Icons and Store Page]].

### Do not copy

1. **Selling power over other players.** Paid admin commands and troll gear that affect others are exactly what press criticised. If you want a premium tier, sell cosmetics or self-only boosts. [[Ethical Design and Player Trust]].
2. **Theft with no protection for new players.** Being robbed in the first minute by someone much richer is a reason to quit. Give newcomers a grace period or steal limits based on income gap. [[First-Time User Experience and Onboarding]].
3. **Licensed meme characters without rights.** The game had to remove a popular character in September 2025 after a licensing dispute and re-added it in November 2025 (Press, Polygon, September 18, 2025, via Wikipedia). If your content is someone else's meme, get permission in writing first.
4. **Trusting the client for steals.** Stealing must be validated on the server: distance to the base, carry state, lock state and cooldowns. Automation scripts were reported in this game. [[Server Authority and Validation]], [[Rate Limiting and Abuse Prevention]].
5. **Assuming viral peaks repeat.** RoWatcher's data shows each spike decays faster. Budget for the floor, not the peak.

### A small build sketch: server-validated steal

```lua
--!strict
-- Server-only check before a steal is accepted. All state lives on the server.
local STEAL_RANGE = 12 -- studs, rule of thumb
local STEAL_COOLDOWN = 5 -- seconds between steal attempts per player

local lastSteal: { [Player]: number } = {}

local function canSteal(thief: Player, baseOwner: Player, base: Model, now: number): boolean
	if thief == baseOwner then return false end
	if (base:GetAttribute("LockedUntil") :: number? or 0) > now then return false end
	if now - (lastSteal[thief] or 0) < STEAL_COOLDOWN then return false end
	local root = thief.Character and thief.Character:FindFirstChild("HumanoidRootPart") :: BasePart?
	if not root then return false end
	if (root.Position - base:GetPivot().Position).Magnitude > STEAL_RANGE then return false end
	lastSteal[thief] = now
	return true
end

return { canSteal = canSteal }
```

Use `workspace:GetServerTimeNow()` for `now` so lock timers shown on clients match the server. Clean up `lastSteal` on `PlayerRemoving`.

## Checklist

- [ ] Does your title contain the core verb?
- [ ] Is the main shop visible to every player at once, so rare items create races?
- [ ] Do you show income as a rate?
- [ ] Is there a risk mechanic with a clear, visible timer and counterplay?
- [ ] Are new players protected from much richer players for their first sessions?
- [ ] Are all steals and purchases validated on the server?
- [ ] Is nothing you sell a way to harm other players?
- [ ] Do you own or license every character you use?
- [ ] Is your next update on a public countdown?
