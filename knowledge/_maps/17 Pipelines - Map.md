# 17 Pipelines - Map

One line per note in `17 Pipelines`: title, then the first TL;DR bullet (or the first sentence).
Generated by `_tools/build_index.py`; open a note's TL;DR block before reading it.

- Art Pipeline - Concept to In-Game Asset: Asset imports 100x too big or rotated 90 degrees: unit or axis mismatch -> test cube, fix exporter settings once, encode in script
- Asset Upload Automation with Open Cloud: Avoid: API key in the repository. Symptom: a leaked key, sometimes found by automated scanners within hours.
- Audio Pipeline: One sound far louder than the rest: not in the loudness table -> gate: unlevelled ids
- Batch Processing Tools in Studio: Studio freezes for minutes: unsliced loop, background work, too many offline processes -> slice under budget; no background loops; cap processes
- Blender Automation with Python: Avoid: Building in the artist's open session. Symptom: a teammate's scene is reset or overwritten.
- Build Test and Release Pipeline: Debug flag live in production: test flags in the live place -> environments; pre-build state check
- Character and Creature Pipeline: Every clip broken after a model update: skeleton re-exported with renamed or re-rolled bones -> keep the manifest; rebuild the look onto it (Blender Armature and...
- Code Pipeline - Rojo Git and CI: Changes in Studio vanish: Rojo synced files over Studio edits -> edit code only in files; keep mapped folders code-only
- Data and Config Pipeline - Spreadsheets to Game: Avoid: Display names as keys. Renaming "Iron Sword" to "Iron Blade" orphans every saved inventory.
- Environment and Level Pipeline: Resize means rebuild: hand-placed macro layout -> layout formulas
- Icon and Thumbnail Rendering Pipeline: Icon colour differs from the game: rendered from the source file only -> merge the exported in-game look
- Live Content Pipeline: Event never started on some servers: started by a message -> schedules in config, computed from the clock
- Localization Pipeline: Avoid: Concatenating translated fragments. Symptom: grammatically broken sentences in other languages.
- Pipeline Design Principles: Avoid: Editing the output instead of the source.
- UI Asset Pipeline: Edit and Play look different: runtime restyling, stale bake -> builders bake; controllers only bind; version attribute
