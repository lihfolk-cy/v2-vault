Generated by `_tools/build_index.py`; open a note's TL;DR block before reading it.

- Buffers and Binary Data: "out of bounds" errors: Offsets start at 0; wrong size; writer did not grow -> Growable writer; size checks
- CollectionService Patterns: Pre-placed objects do nothing: Only connected to the added signal -> Iterate `GetTagged` too
- Error Handling - pcall xpcall and Promise Patterns: `pcall` returned true but an error printed: Error in a spawned thread or handler -> Report back from the thread
- Error Handling and Retries: Player data wiped after an outage: Load failure treated as "new player" -> Distinguish failure from empty; kick or retry
- Events Signals and Connections: Memory grows per round or per spawn: Short-lived object connected to a long-lived signal -> Disconnect on teardown; cleanup bag
- Functions Closures and Upvalues: Recursive function errors "attempt to call a nil value (global ...)": `local f = function` used for recursion -> `local function f`
- Instances Attributes and Tags: A system silently stops working after content is added: Name collision found the wrong child -> Separate folders; `IsA` checks; reserved-name list
- Luau Language Essentials: `attempt to call a nil value (global 'x')` on a rare path: Local function used above its declaration -> Reorder or forward-declare; run a use-before-definition scan
- Luau Performance Patterns with Benchmarks: Benchmark shows 0 ns/op: Work optimised away -> Store results in a sink; use the index as input
- Luau Performance and Native Codegen: Steady frame cost grows with object count: Connection per object -> One shared loop
- Luau Type System and Strict Mode: Avoid: Trusting typed remote handlers. Symptom: server errors or exploits from wrong argument types despite "typed" code.
- Math Vectors and CFrames: Part disappears / huge coordinates: NaN from `.Unit` of zero or divide by zero -> Guard magnitude; validate inputs
- Metatables and OOP - When and When Not: Methods missing after a save/load or remote: Metatable dropped -> Plain data at boundaries; rebuild objects
- Module Scripts and Requiring: Edits to a module have no effect in a test: Cached require in the same VM or a separate command-bar VM -> Clone-require; restart the test
- Parallel Luau and Actors: No speed-up: All scripts in one Actor, or no `desynchronize` -> Many Actors; `ConnectParallel`
- Script Types and Run Context: LocalScript does nothing: In Workspace or ReplicatedStorage -> Starter containers, or a Client-context Script in ReplicatedStorage
- Strings Patterns and Formatting: Search fails on names with `.` or `-`: Pattern magic -> `find(s, text, 1, true)`
- Tables Metatables and OOP: `#list` wrong after removal: `list[i] = nil` created a hole -> `table.remove` or swap-remove
- Task Library Coroutines and Yielding: Client freezes on an action: Unbounded loop without yield -> Cap attempts; yield; check targets exist
