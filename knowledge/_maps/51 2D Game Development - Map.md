- 2D Multiplayer - Server Authority and Replicating GUI Worlds: Avoid: Moving a Frame and expecting others to see it.

- Choosing GUI 2D or Locked-Camera 2.5D: Avoid: Choosing GUI 2D for a multiplayer action game "because it is simpler".

- Tilemaps Cameras and Parallax for 2D Levels: Avoid: Collision derived from visual tiles. Symptom: an artist adds a decorative tile and players get stuck on it.
