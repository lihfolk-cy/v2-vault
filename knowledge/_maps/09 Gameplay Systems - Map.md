# 09 Gameplay Systems - Map

One line per note in `09 Gameplay Systems`: title, then the first TL;DR bullet (or the first sentence).
Generated by `_tools/build_index.py`; open a note's TL;DR block before reading it.

- Behaviour Trees Utility AI and State Machines for NPCs: Avoid: Interrupts duplicated in every state -> Global transitions in a parent
- Camera Systems: Avoid: Shake written into `CFrame` without removal -> Apply at Camera+1, remove at Camera-1
- Characters and Humanoids: Avoid: `SetStateEnabled` on the server for a player -> Run it on the client
- Combat Systems Architecture: Avoid: Damage computed on the client -> Server computes from server stats
- Custom Character Controllers: Avoid: Asking the server before moving -> Act on client, validate on server
- Economies and Currencies: Avoid: Fixed rewards in an exponential game -> Scale to next price
- Hitboxes and Hit Detection: Avoid: `Touched` sword -> Query at hit time
- Mover Constraints and Physics Controllers: Avoid: No force limit -> `ForceLimitsEnabled` + mass-scaled `MaxForce`
- NPC AI and Behaviour: Avoid: Brains every frame for all enemies -> 10 Hz, distance gating, staggering
- Pathfinding Edge Cases and Fallbacks: Avoid: Pathing to the player's root position -> Goal resolver: project down, last grounded position, ring samples
- Pathfinding: Avoid: Default agent size for big NPCs -> Real radius and height per size class
- Physics Assemblies and Constraints: Avoid: Anchoring two parts of a welded prop -> Anchor only the root
- Progression Levels and Unlocks: Avoid: Saving level instead of total XP -> Save totals
- Quests and Objectives: Avoid: Quest code inside combat code -> Signal bus
- RNG Drops and Luck Systems: Avoid: Rolling on the client -> Server rolls only
- Raycasts Shapecasts and Spatial Queries: Avoid: Unit direction vector -> `direction.Unit * distance`
- Spawning Teams and Rounds: Avoid: Relying on random SpawnLocation choice -> Place in `CharacterAdded`
- Status Effects Buffs and Stacking Rules: Avoid: Effects write `WalkSpeed` or `Health` directly -> Modifiers plus one owner that recomputes
- Tools and Inventory Systems: Avoid: Inventory as Tools in Backpack -> Data inventory, Tool only for equipped
