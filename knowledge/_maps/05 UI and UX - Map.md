# 05 UI and UX - Map

One line per note in `05 UI and UX`: title, then the first TL;DR bullet (or the first sentence).
Generated by `_tools/build_index.py`; open a note's TL;DR block before reading it.

- Accessibility: Avoid: `TextScaled` everywhere, ignoring the player's text size.
- Declarative UI - React-Lua and Fusion: Avoid: Starting with Roact in new code.
- Gamepad and Console UX: Avoid: No initial selection when a menu opens.
- HUD Design: Avoid: Hand-positioned HUD elements added feature by feature.
- Input - UserInputService and ContextActionService: Avoid: Gameplay handlers that ignore `gameProcessedEvent`.
- Layout - Scale Offset and Constraints: Avoid: Square icons sized with Scale on both axes (stretched everywhere but the design screen).
- Localization: Avoid: Dynamic labels with `AutoLocalize` on: tables full of "Gems: 1,240".
- Menu Archetypes - Shop Settings Codes Rewards: Avoid: No pending state on claim and buy buttons (double requests).
- Notification and Toast Systems: Avoid: Errors shown as corner toasts -> Inline feedback at the control that failed
- Responsive UI for Phone Tablet Console and PC: Avoid: `TouchEnabled` used as "is a phone".
- Safe Areas and Insets: Avoid: Treating `IgnoreGuiInset = true` as fullscreen (it is device-safe, not fullscreen).
- ScreenGui Fundamentals: Avoid: Screens organised into folders in `StarterGui`, which silently re-enables reset on spawn.
- Text Fonts and Rich Text: Avoid: `GothamBlack` in new code (renders Montserrat).
- UI Design Systems: Avoid: Colours picked per screen instead of by role.
- UI Layout Objects - Lists Grids and Pages: Avoid: Tweening `Position` of a child under a layout (nothing happens).
- UI Motion Language and Timing: Avoid: Hiding on `Completed` without checking state -> Check `Enum.PlaybackState.Completed` and current intent
- Virtualized Lists and Large Inventories: Avoid: Rebuilding all cards on any change -> Rebind only the affected index
- World-Space UI - BillboardGui and SurfaceGui: Avoid: Billboard sized in Scale when you wanted constant on-screen size (or the reverse).
