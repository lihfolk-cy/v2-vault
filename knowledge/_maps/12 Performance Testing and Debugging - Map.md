One line per note in `12 Performance Testing and Debugging`: title, then the first TL;DR bullet (or the first sentence).
Generated by `_tools/build_index.py`; open a note's TL;DR block before reading it.

- Automated Testing with TestEZ and Jest-Lua: Avoid: Testing glue code and UI instead of economy, odds and data.
- Crash and Error Telemetry: Avoid: Relying only on player reports to learn about errors.
- Debugger Breakpoints and Logging: Avoid: Print-driven debugging with prints that never get removed (or that get removed and re-added weekly).
- Developer Console and Stats: Avoid: Reading memory in Studio and trusting it.
- Hunting Memory Leaks Step by Step: Avoid: Calling "memory did not drop after players left" a leak on the server.
- Memory Budgets and Leaks: Avoid: Trusting `Destroy()` to clean up connections made on other objects.
- MicroProfiler Guide: Studio skews the picture. Server and client share the process in a solo test, and Studio has its own UI cost.
- Mobile and Low-End Optimization: Avoid: Testing phones only in the Device Simulator.
- Multi-Client and Device Playtesting Protocols: Avoid: Running a live session for bugs Studio's eight-client test would have found.
- Multi-Client and Live Testing: Avoid: Only ever testing as the first player in the server.
- Network Bandwidth Budgets and Measuring Them: Avoid: Trusting the "50 KB/s per client" folklore as a hard limit.
- Network Performance: Avoid: Large values in attributes on the Player or on Workspace objects that change often.
- Performance Fundamentals: Avoid: Optimising in Studio and declaring victory.
- Physics Performance: Avoid: Unanchored decoration. Check with a script: count unanchored parts not in characters.
- QA Checklists Before Release: Avoid: One checklist for every change, so people skip it for small ones and then skip it for big ones.
- Rendering Performance: Avoid: Judging render cost on a desktop GPU.
- Script Performance: Avoid: Heavy work in `PreRender`/`RenderStepped`.
- Testing Strategies and Frameworks: Avoid: Reporting Edit-mode success as "works".
