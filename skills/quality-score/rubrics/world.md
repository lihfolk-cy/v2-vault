# Rubric: world / zone / level

Sources: worldbuilding, level design and lighting notes; the `roblox-professional-builder` standards if installed. Evidence: Studio MCP screenshots from the spawn, the main path, and an overview shot, plus an instance count and performance stats.

## Hard gates
- No floating or buried props (raycast-checked), no unintended overlaps
- Main path walkable with no invisible blockers; spawn safe
- Static parts anchored; decoration `CanCollide` off where it has no gameplay purpose
- Within the budget (part, triangle and light counts for the target devices)

## Criteria (0 / 1 / 2)
| # | Criterion | W | 0 | 1 | 2 |
|---|---|---|---|---|---|
| W1 | Composition and focal point from the player's view | 3 | none | weak | strong |
| W2 | Navigation readability (paths, landmarks, sight lines) | 3 | lost | ok | obvious |
| W3 | Style cohesion (materials, palette, asset style) | 2 | mixed | minor clashes | cohesive |
| W4 | Lighting and atmosphere mood | 2 | default | tuned | striking |
| W5 | Detail density (no empty flats, no clutter) | 1 | empty or cluttered | uneven | balanced |
| W6 | Scale against the R15 avatar | 1 | wrong | mostly right | right |
