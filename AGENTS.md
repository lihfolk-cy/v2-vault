# AGENTS.md: using LihFolk with any AI coding agent

For Roblox work (Luau, Studio, remotes, DataStores, UI, worldbuilding, modelling, VFX, animation, design, monetisation, performance, security, publishing):

1. **Grep, don't read:** search `knowledge/INDEX.md` (one line per note: `title | path | tags | first sentence`) for the exact APIs and topics in the task. Paths are relative to `knowledge/`.
2. **Read sections, not files:** in the 1-2 best notes (up to 4 for big tasks), read the `## Common mistakes` and `## Checklist` sections, plus the one section that applies.
3. **Apply and cite** the note titles you used.
4. **Trust labels:** prefer `Roblox docs` and `Measured`; verify `Unverified` claims; never invent APIs or asset ids.
5. **Quality bar:** for generated assets and systems, score against `skills/quality-score/rubrics/<type>.md`. Hard gates must pass, and the minimum is 8.5/10. Don't grade your own work alone; get an independent review.

Deeper workflows (Blender modelling, trend games, council review) are in `skills/*/SKILL.md`; any agent can follow them as plain instructions.
