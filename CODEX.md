# LihFolk V2 with OpenAI Codex

This repository provides native Codex skill entries and custom agent profiles while keeping `skills/` and `commands/` as the canonical detailed workflows. Codex loads the small entries from `.agents/skills/`; they point back to this checkout for the full guidance and vault search engine.

## Install in a Roblox project

Use Python 3.10 or newer. On Windows, keep this LihFolk checkout available on the same machine as the game project, then run:

```powershell
py -3 "C:\path\to\v2-vault\scripts\install_codex.py" --project "C:\path\to\my-game" --vault-root "C:\path\to\v2-vault"
```

On macOS or Linux, use `python3` and POSIX paths. The installer copies the Codex skills and three agent profiles, adds a managed block to the project's `AGENTS.md`, and records the local source path and Python executable in `.lihfolk-codex.json`. These absolute paths are machine-specific; the config file is added to `.gitignore` in a Git project. Existing unrelated instructions, skills, agent profiles, hook groups, and Codex feature settings are preserved. Re-run the installer after updating the LihFolk checkout to refresh generated entries.

To use the current checkout directly, open this repository in Codex; its `.agents/skills/`, `.codex/agents/`, and `AGENTS.md` are already present. For a separate game project, open that game project after installation. Skill entries are discoverable by their descriptions and can also be invoked by name when supported by the Codex client.

## What is installed

- **24 skills:** the 22 canonical LihFolk skill workflows plus `lihfolk-vault-search` and `roblox-project-audit` entries.
- **Three agent profiles:** focused vault lookup, independent council review, and council synthesis. They inherit the parent Codex session's permissions; instructions asking an agent not to edit are not a permission boundary.
- **A vault-search helper:** forwards arguments to the existing `LihFolk Vault V2/_tools/vault.py` and supports paths with spaces. `.lihfolk-codex.json` or `LIHFOLK_VAULT_ROOT` identifies the source checkout.
- **No asset pack:** the installer does not download or copy optional asset releases.

The entries are generated by `scripts/sync_codex_skills.py` and intentionally keep the detailed licensed material in its canonical source files. When following a source guide, Codex should treat `CLAUDE_PLUGIN_ROOT` as the configured LihFolk source root and use its available tools instead of Claude-specific tool names or slash commands.

## Optional post-edit Luau checker

The original LihFolk checker can run after Codex edits `.lua` or `.luau` files. Install it explicitly:

```powershell
py -3 "C:\path\to\v2-vault\scripts\install_codex.py" --project "C:\path\to\my-game" --vault-root "C:\path\to\v2-vault" --enable-hooks
```

This adds a project-local Codex hook and enables the `codex_hooks` feature in `.codex/config.toml`, preserving existing hooks and unrelated feature values. Inspect and trust the project hook in Codex before use (`/hooks` in the CLI or the Hooks settings in the app). Hooks run only for a trusted project. The adapter checks only changed Luau files under the game project and skips vendored directories. It passes findings to Codex; checker errors can mark the post-edit result as blocked for model feedback, but the edit has already happened and is not reverted. A checker runtime failure reports context without blocking the edit.

The scanner uses the same heuristic rules as the existing Claude hook; findings can be false positives or miss cases that need cross-file/type analysis. See [hooks/README.md](hooks/README.md) for rule coverage, severity, and known limitations. This is feedback for review, not a security sandbox or a replacement for testing in Roblox Studio.

## Search examples

The installed `lihfolk-vault-search` skill can search task wording, read a note section, or check an API. On Windows, use `py -3`; if Codex's shell cannot find it, read the `python_executable` field in `.lihfolk-codex.json` and invoke that path from PowerShell:

```powershell
py -3 ".agents/skills/lihfolk-vault-search/scripts/vault_search.py" "player data session locking"
py -3 ".agents/skills/lihfolk-vault-search/scripts/vault_search.py" --read "DataStore Fundamentals" "UpdateAsync"
py -3 ".agents/skills/lihfolk-vault-search/scripts/vault_search.py" --api "TeleportService.ReserveServerAsync"
```

The helper uses the configured vault source. It does not scan the machine for a checkout. For high-stakes work, read the full `Common mistakes` and `Checklist` sections and cite the note titles used.

## Maintenance and verification

Regenerate checked-in skill entries after source skill changes:

```powershell
py -3 scripts/sync_codex_skills.py
py -3 -m unittest discover -s tests -v
```

The installer is repeatable, refuses to replace unmarked skill or agent files, and preflights planned writes before applying them. It does not modify the Claude plugin, hooks, agents, commands, or manifest.
